# Tabela de preços para a IA de orçamento — PARA O DONO PREENCHER

A IA de orçamento **não inventa preço**: ela entende o caso e escolhe os fatores, e o código calcula a faixa com esta tabela. Preencha os campos `R$ ___`. Pode ser aproximado: a tabela é versionada e vai sendo calibrada com as propostas fechadas.

Como o cálculo funciona:

```
faixa = (base do serviço + soma dos adicionais) × multiplicadores
mínimo da faixa = valor calculado × (1 − margem de incerteza)
máximo da faixa = valor calculado × (1 + margem de incerteza)
a faixa nunca fica abaixo do piso do serviço
```
